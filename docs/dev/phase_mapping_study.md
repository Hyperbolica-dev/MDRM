# 相位观测映射与最小转移模型研究

2026-10-05。研究对象是相图坐标是否表示同一个周期事件，以及图中的逐日方向是否有可预测性。本轮没有修改生产 P 或原始记录。

## 1. 可复现反例：午睡被画成主节律提前

设置目标起床 08:00、睡眠参照 8h；主睡眠固定为 00:00–08:00。

| 情形 | 旧代理 e | 主窗口候选 e | 区间圆周中心候选 |
|---|---:|---:|---|
| 仅主睡眠 | 0h | 0h | 0h |
| 加 14:00–15:00 午睡 | −0.5h | 0h | 向更晚的分布中心移动 |
| 00:00–08:00 内清醒合计 1h，位置未知 | +0.5h | 窗口中心 0h，净睡眠重心范围 ±0.5h | 不输出伪精确中心 |
| 等量分段 00:00–03:00、04:00–07:00 | 0h（按现有代表段） | 无唯一主窗口 | −0.5h |
| 等量对置 00:00–04:00、12:00–16:00 | 取决于代表段 | 无唯一主窗口 | 合向量相消，方向未定义 |

旧代理把全天睡眠时长都从一个起床时点向前减，因此加午睡会使相位机械地提前。净睡眠量变化也会被误当成时点变化。对 e 求差分后，这些变化进入 v 和目标函数，进一步被解释为移相或波动。

## 2. 两个候选各自回答不同问题

**唯一主窗口中点**回答主要睡眠事件发生在何时。合并相接的零觉醒片段，最长净睡眠至少 3h 且严格占当天总净睡眠的一半以上才定义主窗口。它能抵抗短午睡干扰；代价是分段睡眠可能没有单一主锚点。清醒位置未知时，窗口中点并非实际睡眠重心，因此报告净睡眠重心可能偏移的半宽。阈值是研究操作规则，不是生理定义。

**全天区间圆周中心**回答睡眠在 24h 圆周上的总体分布方向。对整个区间积分单位复向量，避免简单按片段中点平均造成拆分依赖。它保留午睡信息，但午睡改变整体中心是定义本身的含义，不能解释为主节律已移相。方向相消时不输出中心；低集中度说明单一中心可能不充分，不是低生理振幅。

两者均是日志代理。MCTQ 的 [原始项目说明](https://www.thewep.org/documentations/mctq/item/mctq) 将自由日睡眠中点用于 chronotype，并区分工作／自由日及补偿睡眠背景；本项目不具备这些区分，不能把单日日志候选称为校正 chronotype。圆周方向计算依据见 [SciPy circmean](https://docs.scipy.org/doc/scipy/reference/generated/scipy.stats.circmean.html)；区间积分和唯一主窗口规则为本研究设计。

## 3. 实际日志只读审查

`scripts/study_phase_mapping.py` 从既有 CSV 重建睡眠段，不写回或去重原记录。重叠日不重复积分。私人数据汇总保存在 gitignored 的 `reports/phase_mapping_study.json`，包括候选覆盖率、连续日对数量、共同日期上的定义差异和转移预测结果。

参照显式来自 config.yaml，不隐式采用 UI overrides；相位定义之间的差异、连续漂移与预测误差在共同平移目标下不变。合成反例说明旧代理与主窗口候选可能出现明显差异。主窗口可解释性更直接，但覆盖下降；没有选取使 J 最低的候选，更没有通过删除难预测日提高表现。

## 4. 最小动态模型未胜过持续性基线

比较：保持当前相位、延续当前漂移、只用过去数据拟合 ρ 的受限漂移模型。预测模型 e_(t+1)=wrap(e_t+ρv_t)，网格 ρ∈[-1,1]，8 个训练三日样本是固定启动门槛，不是统计保证。每次只使用预测前已知的历史；所有误差在圆周距离上计算。

研究应按每个候选内部的同日期误差与持续性基线比较。若未获得可靠改善，则不能部署惯性预测、自然吸引场、恢复时间或干预最优路线。不同候选测试日期不同，也不能凭总误差略低就断言某个相位定义更接近真实生理相位。单次数据集与模型族的比较不是所有动力模型均有效或无效的证明。

## 5. 差分可以制造“回摆”，但并非唯一解释

假设真实相位暂时固定，只存在独立同方差观测误差 ε_t：

- e_t=θ+ε_t；
- v_t=ε_t−ε_(t−1)；
- Var(v_t)=2σ²；
- Cov(v_t,v_(t+1))=−σ²，因此相邻漂移相关可达到 −1/2。

这条局部未跨接缝的推导不需要真实反馈或振荡，就能产生交替方向。故拟合得到负 ρ 并不能证明身体会主动回到目标。当前 e–v 图应理解为观测返回图；实际回摆可能包括差分噪声，也可能来自药物、通宵等真实扰动，现有推导不能判定其组成。

下一阶段应比较包含观测误差的最小圆周状态观察器与持续性基线，而非直接把噪声流场平滑成吸引子。真实观测、状态估计、条件预测必须分开；不能通过平滑后 J 降低宣称行为改善。重复记录、未知觉醒与不唯一主窗口决定观测质量，不能假定所有点精度相同。

## 6. 决策

保留生产定义以保证研究可追溯，本轮候选只用于研究比较。主节律同步问题优先研究唯一主睡眠锚点；多段睡眠作为可能不同的模式显式处理，不逐日自动在两种定义间切换，否则切换本身会制造漂移。全天圆周中心保留为睡眠分布描述。

接下来的核心任务：建立同一采样事件与观测误差模型；在不额外录入的条件下进行时间顺序验证；仅在胜过基线且误差可靠时，把条件预测带入目标函数。现有资料不能辨识的生理相位与控制作用不以假定箭头替代。

必要验证：映射与既有目标函数 12 项、新增转移评估 2 项测试通过。覆盖午睡反例、区间拆分／顺序不变、圆周接缝、对置相消、觉醒时序范围、时间缺口以及未来数据不影响过去预测。未运行浏览器或截图，未重跑外围 UI 测试。

后续：[事件分层研究](phase_event_study.md)区分预测前上下文与事后事件窗口，并报告通宵/药物事件的评估覆盖；不将未标记组解释为无药对照。
