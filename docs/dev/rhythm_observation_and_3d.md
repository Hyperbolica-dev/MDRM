# 节律观察与三维展示：证据及实现

2026-10-04。范围：开头展示日历和今日分析，不增加原始记录字段，不请求浏览器或截图。

## 今日分析解释什么

开头先显示日历、累计记录天数和所选月份记录天数，再显示今日分析。计数按实际填写日期去重，不按睡眠段计数，也不计入推断的缺失日。今日分析标明依据的最近记录日期。

将“偏离目标”“起床一致性”“模型睡眠债”分别报告。起床一致性用最近 7 个日历日内有效相邻日的圆周起床差中位数（分钟），附有效对数；少于 3 对不汇总。它直接复用已录入时间，比一个未经标定的百分比更容易解释，也不会把高平均分误称为“正在改善”。P/D/H 动力学参数本次没有改变。

## 文献对公式的约束

| 来源 | 可支持的解释 | 不据此推出的结论 |
|---|---|---|
| [Phillips et al., 2017](https://doi.org/10.1038/s41598-017-03171-4) | 睡眠时长与规律性应分开；SRI 比较间隔 24 小时的睡/醒状态 | 起床差或 H 不等于 SRI；观察关联不构成个体因果预测 |
| [Fischer, Klerman & Phillips, 2021](https://doi.org/10.1093/sleep/zsab103) | 指标对相邻日变化、周模式、午睡、觉醒、通宵和样本长度的响应不同 | 不存在可不加条件替换当前指标的万能规律分数 |
| [Murray et al., 2019](https://doi.org/10.1016/j.sleep.2019.03.009) | DSWPD 人群的功能与规律性、睡眠相对生物钟的时间关系有关 | 不把“更早”作为普遍健康结论；本界面早在上仅是用户指定的阅读方向 |
| [Ochab et al., 2021](https://doi.org/10.1371/journal.pone.0255771) | 恢复表现随测量指标而异 | 文中活动持续时长分布的指数拟合不能验证 MRDM 债务恢复式或 k=0.4 |

短期不引入 SRI：现有缺失日不能视为清醒；仅知道“清醒合计分钟”时，无法定位每个 24 小时匹配样本的睡/醒状态。强行计算会隐含未观测的数据。现有日志可以支持圆周时刻差、中位数、样本覆盖率及星期模式，因此优先改善这些解释，不要求用户增加记录。

债务公式参数仍属于待校准假设。文档修正饱和极限：恢复项的最大幅度是 kD，叠加衰减后总乘子趋向 λ−k=0.5；原先 D=12→7.2 及“三夜低于 1”并非所写公式的完整结果。该修正不改变运行时方程或既有数据。

## 三维图用于回答什么

| 展示 | 适用问题 | 取舍 |
|---|---|---|
| P–D 二维 | 最近是否接近所选目标区 | 保留为主要比较视图 |
| P–D–时间 | 同一个 P/D 区域是否反复经过、何时发生偏移与恢复 | 本次三维实现；不增加观测维度 |
| P–D–H | 状态变量之间的模型关系 | H 是平滑派生量，作为第三轴容易被误读为独立观测；暂不替换时间轴 |
| 多个二维投影 | 消除遮挡后比较某一对变量 | 通过同一三维数据的固定正交视角实现 |

研究参考：[GraphDice / AVIZ](https://www.aviz.fr/graphdice) 展示了多属性组合间导航的思路；[Plotly 相机文档](https://plotly.com/python/3d-camera-controls/) 与 [projection API](https://plotly.com/python-api-reference/generated/plotly.graph_objects.layout.scene.camera.html) 支持正交与透视相机。以下是本项目的设计判断，不是已做过用户实验的可用性结论：

- 默认斜视，避免正上方视角把时间维压扁；提供 P–D、P–时间、D–时间固定视角，减少手工旋转负担。
- 使用正交投影，减少近大远小造成的比较误差；显示比例固定但各轴单位不同，不用空间欧氏距离定义健康分数。
- 灰到蓝表示旧到新，金点同时标出日期。悬停给出日期、P、D、相对天数与估计状态。
- 全轨迹连线与时间颜色分组分开，避免分组边界断线；真实缺失日、无效相位及直角坐标接缝仍断线。
- 在最新日期平面画目标区边界；该边界只表示所选 P/D 阈值，不代表正式七日吸引域判定。
- 保持原有时间范围筛选。观察视角只改变展示，不写入睡眠记录。
