# MRDM：以相位为核心的目标、状态与可视化

2026-10-05。用户确认：目标偏移与日间波动共同优化。本文区分已经实现的行为相位返回图与下一阶段的受控动力学，不将二者混称。

## 核心问题不是图是否平滑

睡眠是周期过程。健康的连续轨迹不会停在某个最低压力点；睡醒压力本来就应往复变化。相图应帮助理解周期如何相对目标锁定、偏移后如何返回、调整是否引起振荡。只展示 P–S 的点云或密度不能自动回答这些问题。

旧目标 `-β Var(P)-γ D-η R` 有三个结构问题：稳定偏离目标仍能得到零相位方差；普通方差跨 ±12h 接缝会失真；D 已退役，R 又依赖尚未验证的恢复判据。这不是换配色能解决的。

## 两种“相”必须关联而不混同

- 生理振荡器相位 φ：沿昼夜极限环前进的位置，需要生理模型与观测方程估计。
- 行为相位误差 e：日志推导睡眠时间相对于指定目标的圆周偏移，当前可以计算。

连续系统的理想对象是**参考周期轨道**；若每天在相同事件采样，并换到相对目标的坐标，周期同步才可能表现为返回图中的固定状态。这解释了为什么系统仍每天睡醒，而逐日图可以接近固定点。

目前的 P 使用代表性起床时间减去全天总睡眠的一半，因此午睡会影响它，且 P 和 S 不一定采样于同一事件。现有数据支持行为代理的返回图，尚不支持把 P–S 连线叫作真实生理轨道。下一步观测模型应优先比较“主睡眠中点”“全天睡眠的圆周重心”“当前代理”对分段睡眠、午睡和未知觉醒的响应；不能仅凭更漂亮的轨迹选择代理。

## 已实现：误差—漂移返回状态

`e_t=P_t`，`v_t=wrap(e_t−e_(t−1))`，只使用连续有效日。v 是每日相位变化，不是连续瞬时速度。返回状态为 z=(e,v)，目标为 (0,0)：

- e≠0、v≈0：稳定在偏离目标的位置。
- e≈0、|v| 大：刚经过目标，还没有稳定。
- e 与 v 的组合沿轨迹逐步靠近 (0,0)：观测支持正在对齐并减缓漂移。
- 来回跨越目标：可能是调整过度、外部扰动或观测噪声；轨迹自身不能区分原因。

定义 ℓ(x)=(1−cos(πx/12))/2，j=0.5ℓ(e)+0.5ℓ(v)。两个分量同为无量纲圆周损失，默认等权是设计选择。窗口 J 仅平均同一组有效连续日对，不因某一项缺失而重新分配权重；至少三对才显示汇总。J=0 的已观测作息确实同时对齐且不漂移，但不证明抗扰稳定性或生理恢复。

目标函数不会制造睡眠充分性：稳定的短睡仍可能得到低 J。因此真实优化必须有独立的睡眠机会／睡眠量与可执行性约束。当前并列显示睡眠参照缺口的日数，不能把该缺口兑换成目标奖励，也不把它累计成待偿还小时。

## 相图直接服务目标函数

1. **核心展开图**：横轴 e，纵轴 v，星号 (0,0)，背景为 j 的等高线。局部尺度随观测适配但始终包含目标；这是偏好函数，不是测得的势能。
2. **圆周读法**：角度 15e 度，半径 13+v。虚线环为 v=0，内侧逐日提前、外侧逐日延后；目标在零漂移环的目标角度。圆心没有最优含义。
3. **轨迹**：长窗口保留状态点，近期七日连接显示先后，缺日和接缝断开。点颜色编码时间；没有预测模型时不画预测流场或“最优路线”。
4. **P–S 辅助图**：解释压力条件与观测分布，保留在辅助观察区，不再与核心优化目标争夺主图。

这不是把散点图改名为动力学：e–v 是可观测的延迟坐标，不保证满足马尔可夫性，也不保证可以仅凭它预测下一步。它先解决用户如何理解目标与运动的问题。

## 下一阶段：受控相位动力学

机制层可采用圆周振荡器与睡眠稳态的混合系统：

- dφ/dt=ω+Z(φ)u_light+ξ_C；
- 清醒时 dS/dt=(1−S)/τ_w，睡眠时 dS/dt=−S/τ_s；
- 睡醒切换由 φ、S 与行为安排共同决定；
- 日志通过观测映射 h(φ,S,安排) 与模型连接，而不是直接令 φ=P。

这些是研究结构，当前没有新增实现或个体参数。缺少光照记录时，u_light 不能用“建议已展示”代替；未观测输入可作为扰动，但不能据此辨识个人 PRC。参考参数情景仍可用于解释与比较，并明确其来源。

数据层的第一步不是训练大模型，而是比较受约束的圆周持续性／漂移模型，按时间滚动预测下一日。最低基线 e_(t+1)=e_t；检验圆周误差、区间覆盖与残差是否优于基线，再判断 S 或短历史是否提供额外解释。没有可辨识控制数据时，不能用观测相关性填上干预系数。

控制层再解滚动问题：在睡眠机会、调整幅度和执行条件约束下，选择有限时域的 u，使未来 j 与控制代价之和最小。用户目标只进入代价或控制律，不能偷偷作为生理系统自然会被吸引到的点。若没有控制作用，数学上的“下坡方向”也未必能实现。

## 研究依据与边界

- [Yin, Julius & Wen, 2021](https://journals.plos.org/plosone/article?id=10.1371/journal.pone.0251478)：联合 Process C 与 S 的模拟优化，与只考虑 C 的快速移相方案不同；支持将睡眠过程纳入控制约束和状态。它不验证本人的参数或本项目的 j。
- [Optimal adjustment of the human circadian clock in the real world, 2021](https://journals.plos.org/ploscompbiol/article?id=10.1371/journal.pcbi.1008445)：研究在现实明暗安排约束下进行节律优化，支持可执行性是问题本身的一部分，而不是图画完后的附加条件。
- 圆周损失、e–v 返回图、等权和三对展示门槛为本项目的明确设计选择。它们不是临床阈值，也不是以上论文给出的个体处方。
