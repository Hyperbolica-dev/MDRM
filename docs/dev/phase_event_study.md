# 事件分层与相动力学可辨识性

2026-10-05。研究方法文档，不是额外审计报告。生产相位、目标函数和原始记录未改动；本轮不要求增加用户输入。

## 问题与可辨识边界

观察到的睡眠行为相位可概念性写成 y_t = wrap(θ_t + b_t + ε_t)：θ 是内源相位，b 是睡眠安排、药物等造成的行为与内源相位关系变化，ε 是记录及观测误差。内源相位也可能受外部作用而改变。这里只有一个日志代理和粗粒度事件标记，无法唯一分解三项；这是研究结构，不是已拟合的新生理方程。

[睡眠剥夺实验](https://pubmed.ncbi.nlm.nih.gov/12932197/)在特定同步条件下观察到睡眠剥夺及伴随昏暗光照之后褪黑素相位延迟，不能将这一复合暴露归因于睡眠剥夺单一因素，更不能移植为用户的通宵移相系数。[Lewy 等的原始研究](https://pubmed.ncbi.nlm.nih.gov/10452335/)说明相位标志本身也受 masking 与测量定义影响。两者支持区分真实变化与观察方式，不支持从日志回摆自动选定一种原因。

不需要用户提供私人药物细节才能承认这种不确定性。即使补充细节，也不自然获得因果识别；用药往往是睡不好之后作出的选择。

## 已实现的研究路径

运行 `PYTHONPATH=. python scripts/study_phase_events.py`，读取原始记录，输出 gitignored 的 `reports/phase_event_study.json`。个人事件数量、预测误差和分层结果只保存在本地输出，不纳入公共文档或提交。

1. 按同一节律日汇总助眠药物、重大扰动、显式零窗口事件。字符串 False 不转成真；缺失日期不生成通宵事件。同日补觉不抹掉已记录无主睡眠事件。
2. 复用旧代理、主窗口中点、全天区间圆周中心三个候选；仅连续且两个漂移均可辨识的三日组用于回摆分析，半周歧义或相位缺失打断样本。
3. `prior_*` 只看前两日，是预测前已有的日期上下文。`window_*` 看完整三日，只用于事后分层，不能用于选择当时的预测器。由于现有日志没有录入时间，此处是按事件日期顺序的回测，不声称还原当时实际已录入的信息。
4. 每个日期复用仅过去拟合的 ρ、持续性和延续漂移预测。分层只比较完全相同预测日期的圆周误差，不重新挑选最优参数。
5. 同时输出每类事件总天数、三日组数、回摆数、进入前向评估的组数及误差。分类可重叠，不相加成总样本数。相邻三日组共享日期，并不是独立重复实验。

没有记录标记不等于确认未用药；来源未区分的默认 False 不能成为生理对照。缺失事件上下文也不进入 unmarked 组。主窗口更严格的覆盖条件可能改变事件构成，不能跨候选直接比较总体误差判断生理真实性。

## 对核心设计的推进

相图首先应表现“观察状态—目标—事件上下文”。药物介入是轨迹上下文，不是减分项，也不自动从联合目标函数中排除。标记点保留真实位置，不能为了画出漂亮吸引域删除。

- 位置与颜色继续表达目标偏移、逐日运动和时间；事件用独立符号/悬浮信息表示，避免把用药日画成某种好坏等级。
- 通宵缺少相位时放在日期事件带，不强行放到极坐标原点，也不跨缺失处连成平滑移相线。
- 观察坐标、候选状态估计和条件预测分层显示。仅有 y 的平滑线应称为平滑描述，不能称为内源相位或已恢复的身体轨迹。
- 回摆可以是真实调整、映射变化或观测误差；不以负 ρ 或视觉回圈宣布存在恢复吸引子。
- 若某种候选的可评估样本全部落在事件窗口内，直接报告缺乏分层对照，不训练“有药/无药”双模型掩盖样本缺口。

以上为下一步可视化约束，本轮没有改生产图表。事件标记必须沿用已有日志；不以完成药物 journal 为前置条件。

## 已执行：因果圆周平滑比较

采用预先固定的 α=0.25、0.5、0.75、1；α=1 即持续性。每次先预测当前原始观测，再更新圆周状态。缺日/未知相位重置；恰好半周的创新先评分再重置，不任意决定旋转方向。所有增益使用相同日期，同时单列与既有转移模型共同的测试日，避免比较不同样本覆盖。

输出包含逐增益平均圆周误差、相对持续性的配对误差差值，以及时间前后半段的描述结果。前后半段检查是探索性稳健性检查，不是独立预留测试集；不报告未经验证的统计显著性，不按每段挑最优增益。误差评分针对未来原始观测，绝不使用平滑后的 J。完整私人结果与数据内容 SHA-256 指纹留在本地报告；每次运行只读取一次源文件，以避免运行中新增记录影响同次比较。

研究实现为 `model/phase_observer.py`，尚未接入生产图表。即使平滑改善预测，也只能说明对行为日志代理有预测价值，不能单独识别噪声方差、药物效应或内源相位。较强平滑可能滞后于真实突变；下一步应在共同日期比较逐日绝对误差分布及事件窗口中的滞后，确认改善是否以掩盖真实调整为代价，再考虑显示“预测参考轨迹”。

必要验证：5 项事件边界测试、4 项因果圆周观察器测试及 2 项既有时间顺序预测测试通过。覆盖未来事件不进入 prior 上下文、同日补觉、False 字符串、相位缺失、未知上下文、共同评分日期、圆周半周歧义和日期空档。
